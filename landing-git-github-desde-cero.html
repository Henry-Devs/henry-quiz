Preguntas frecuentes

¿Necesito saber programar?
No. Arrancamos desde cero y trabajamos sobre un proyecto ya empezado, así que puedes seguir la clase sin experiencia previa.
¿Git y GitHub son lo mismo?
No. Git es el sistema de control de versiones que corre en tu computadora; GitHub es la plataforma en la nube donde se guarda y se comparte ese proyecto.
¿GitHub es gratis?
Sí. La cuenta personal es gratuita e incluye repositorios públicos y privados.
¿Sirve si no me dedico al desarrollo?
Sí. Cualquier proyecto con versiones —documentación, análisis de datos, automatizaciones— se versiona y se comparte igual.
